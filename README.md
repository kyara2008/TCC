## 3.Como usar ##

### Pré-requisitos
- Ter o **Node.js** instalado no computador.
- Ter o arquivo `.env` configurado na raiz do projeto com o banco de dados Neon e as credenciais de e-mail.

### Passo a passo para executar:

1. **Abra o terminal** na pasta raiz do projeto (no VS Code: `Ctrl + '` ou menu `Terminal > Novo Terminal`).

2. **Instale as dependências** (caso esteja executando pela primeira vez):
   ```bash
   npm install
   npm --prefix frontend install
   ```

3. **(Opcional) Teste a conexão com o banco de dados:**
   ```bash
   npm run test-db
   ```

4. **Inicie o programa:**
   ```bash
   npm start
   ```

5. **Acesse no seu navegador:**
   Abra o navegador e acesse:
   ```text
   http://localhost:3000
   ```

> **Dica:** Para encerrar a execução do servidor, pressione `Ctrl + C` no terminal.
